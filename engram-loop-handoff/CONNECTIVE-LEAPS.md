## The dependency spine

Everything routes through one enabling fact, confirmed independently by four sweeps:
**REFA's update is exactly a constant-gate gated delta rule**, so the WY/Householder
chunkwise algebra applies *exactly* — not approximately. The kernel (leap 1) is therefore
the substrate every other leap rides on; the spectral gate (leap 2) is the zero-cost
expressivity unlock the state-tracking theorems demand; the evidential family (leaps 3-4)
replaces the least-trustworthy component (a trained 3-logit head) with measured and
certified quantities; the temporal family (leaps 7-8) gives memory a queryable "when"; the
provenance ledger (leap 9) turns reads into exact citations. Tier 2 adds new capabilities
(one-shot retrospective writes, typed unknowns, context clones, adaptive forgetting);
Tier 3 is research science — publishable whether it wins or loses.

## Direct adoptions from the sweeps (not novel, just do them)

1. **State-passing post-training** for length extrapolation: carry final bank/workspace
   states across training batches for a short post-training phase (~0.1% budget) so
   long-horizon states are visited (Buitrago Ruiz & Gu, ICML 2025).
2. **Report extrapolation as medians + IQR over >=10 seeds** — length generalization is
   high-variance across seeds (Zhou et al. 2024); mean curves mislead.
3. **smECE / distance-to-calibration, never binned ECE**, at REFA eval sizes; the synthetic
   generator knows true evidence counts, enabling exact epistemic-calibration audits.
4. **ACI conformal wrapper** on the unknown decision: distribution-free coverage on
   non-exchangeable streams at O(1) state; never train "unknown" as a penalized action
   (Aug-2026 collapse law).
5. **Crosstalk instrumentation as a first-class metric**: log measured key coherence mu and
   SNR = sqrt(R/(T-1)) per bank per run; it is the capacity law all design bets price against.
6. **DMFT marginal-stability initialization** for the GRU workspace (Krishnamurthy-Can-Abbott
   PRX 2022) instead of generic edge-of-chaos.
7. **Binding upgrade path**: the additive identity embedding leaks components into the key;
   rotation-bound (s,r) keys (RotatE = Fourier-HRR) are the field-tested fix at D=64-256,
   with resonator networks as the audit/unbinding tool.
8. **MoM-style load balancing + straight-through top-k** when sparse routing lands; routing
   multiplies capacity only if writes are hard.
9. **New battery members** implied by theory: parity-of-negations chains, recency-ordering
   probes, regime-return (context clone) tasks, delayed-evidence curves, fan-effect ladders.
10. **ACT-R declarative equations** as the classical baseline for the evidential head —
    a 40-year-old closed-form retrieval calculus (power-law base-level activation, fan
    effect, logistic retrieval noise) the battery should compare against.

## Tier 1 — adopt now: exact algebra, certified semantics, near-zero cost

### 1. Stance-Folded Chunkwise WY Kernel under the Float64 Gate (one graph, sixteen heads)
*Origin: edge-systems lens.* **Editorial note:** THE SUBSTRATE. Everything else inherits this kernel and its float64 gate.

**Fuses.** fastweight-math (WY/Householder chunkwise form of the gated delta rule; GDN constant-gate case) + ml-scout RTX 2060 engineering facts (Triton main dropped SM 7.5; launch-bound Python loop ~65ms/seq of pure launch overhead; CUDA-graph capture; fp16-not-bf16 on Turing) + the repo's existing float64 output+gradient equivalence discipline (src/refa_edge/benchmarks/equivalence.py).

**Mechanism.** Map each (bank h, stance s) pair to a head of ONE chunkwise gated-delta recurrence: fold routing, gate, and the history mask into a per-head effective learning rate beta_eff[t,h] = sigmoid(w.x_t) * r_h(t) * 1[is_history], and fold stance into a value mask v'[t,s] = 1[s = polarity_t] * tanh(W_v x_t). REFA's transition (lambda_h I - beta_eff k k^T) is exactly GDN with constant gate, so a chunk of C steps collapses to one unit-lower-triangular solve (UT/WY) plus batched matmuls per head — implemented in pure PyTorch batched ops (no Triton, so it runs on SM 7.5), with the whole forward captured in a single CUDA graph (legal because refa.py's loop has static shapes and no data-dependent control flow). GRU workspace stays as-is; only the 16 memory recurrences are chunked.

**Math.** Per head, chunk of C: P = prod_{t=1..C}(lambda I - beta_t k_t k_t^T) = lambda^C (I - sum_t w_t k~_t^T) with decay-scaled keys k~_t = lambda^{-t} k_t and W = T K~, T = (I + tril(diag(beta) K~ K~^T, -1))^{-1} diag(beta) — an R x R (R=16) triangular solve. Cost: O((T/C)(C^2 R + C R D)) matmul flops replacing T*~18 kernel launches; launch overhead ~T*18*7us ≈ 65ms at T=512 collapses to one graph replay. BPTT activation memory for the two memory tensors drops from T*B*2*H*R*D*4B (≈400MB at T=200, B=32) to (T/C)*B*2*H*R*D*4B ≈ 13MB at C=32 plus per-chunk recompute. The rewrite is algebraically exact, not an approximation.

Searched HF Hub via MCP for 'chunkwise deltanet turing cuda graph' (zero hits). Cross-checked all 17 sweep digests, which collectively scanned the 2024–2026 delta-rule kernel literature: DeltaNet/GDN/FLA chunkwise kernels and MoM routing each appear, but no cited work folds (routing weight x stance value-mask x history mask) into per-head WY learning rates for an opponent (M+/M-) evidential memory, nor targets pre-Ampere GPUs via pure-PyTorch WY + CUDA-graph capture verified against a float64 reference-loop gate.

**REFA payoff.** Cost budget: 0 new params; activation VRAM ~30x lower (400MB -> ~13MB for memory tensors at T=200/B=32), unlocking T=2000+ or B=256 training inside 6GB; wall-clock 10–50x (launch-bound to matmul-bound). Equivalence discipline: a new pytest mirroring check_dense_stream_equivalence — chunkwise vs Python-loop REFAMicro in float64 must match outputs AND grads to <=1e-9 (exact rewrite, so a hard gate, not a tolerance excuse). The Python loop is retained as reference semantics; every later leap that touches the kernel inherits this gate. This is the enabling substrate for length-extrapolation sweeps, multi-seed batteries, and every other leap below.

**First experiment.** Implement forward-only chunkwise in float64 for a single (bank, stance) head (~80 lines beside src/refa_edge/models/fast_weight.py), run both implementations on the current revision-task config, assert max abs error <=1e-9 in the existing pytest style; then benchmark scripts/benchmark.py wall-clock at T=512, B=32 in three modes: loop, chunkwise, chunkwise+CUDA-graph. Total: <1 GPU-hour on the 2060.

CUDA-graph capture breaks if dropout RNG or DataLoader shapes vary — pad to static shapes.

### 2. Dual-Mode Spectral Write Gate with a runtime contraction certificate and a parity-of-negations task
*Origin: edge-systems lens.* **Editorial note:** Zero-parameter expressivity unlock mandated by the state-tracking theorems; ships with its own falsifying task.

**Fuses.** math-frontiers contraction analysis (spectrum of lambda I - beta r k k^T) + fastweight-math Longhorn implicit/proximal update (unconditional stability, eps = beta/(1+beta)) + Grazzi/Sarrof negative-eigenvalue state-tracking theory + the repo's gate discipline. What is NEW beyond the digest's one-line 'multiply by (1+lambda)' suggestions: a config-switchable safe/expressive pair sharing one parameterization, a per-batch spectral certificate logged by the benchmark runner and asserted in pytest, and a purpose-built task family that separates the modes.

**Mechanism.** write_gate_mode config: 'safe' — beta = softplus(w.x), effective rate eps = beta/(1+beta) in (0,1) (Longhorn's closed-form proximal step: never overshoots, removes sigmoid saturation, eigenvalues stay positive); 'expressive' — beta = (1+lambda_h)*sigmoid(w.x), putting the key-direction eigenvalue lambda_h - beta*r in (-1, lambda_h): negative eigenvalues unlock parity-class revision tracking (an alternating supported/opposed/supported chain IS parity of negations, which the current spectrum in (lambda-1, lambda) ≈ (-0.005, 0.995) provably cannot track at any width). Runtime contraction monitor: per batch, compute rho_hat = max_{t,h} max(lambda_h, |lambda_h - beta_t r_{h,t}|) and log the running product bound; in safe mode pytest ASSERTS rho_hat <= 1 + 1e-6 (a stability certificate in the equivalence-gate style); in expressive mode the runner logs it as a standard metric so instability is measured, not anecdotal. New task in data.py: parity-of-negations chains (N alternating retraction events, label = parity), train length 16, test 64.

**Math.** Spectrum of the transition: {lambda_h - beta r on span(k); lambda_h multiplicity R-1}. Safe: eps in (0,1) ⇒ all eigenvalues in (lambda-1, lambda) ∩ (0-side bounded), ||A_t||_2 < 1 unconditionally (contraction certificate). Expressive: beta in (0, 1+lambda) ⇒ |lambda - beta r| <= 1, product norm bounded by 1; parity requires an eigenvalue near -1, reachable only here (Sarrof/Grazzi: eigenvalue range [0,1) confines to a proper subclass of regular languages; extending to (-1,1) adds parity/reflections).

**REFA payoff.** Cost budget: 0 new params (same Linear gate, different squashing), 0 VRAM, ~0 wall-clock (elementwise); the monitor is O(B*H) scalars per step, negligible, and computed for free inside the leap-1 kernel from beta_eff. Negative eigenvalues act only along the routed key direction, so parity capacity is per-fact, not global. Straight-through effects if beta saturates at (1+lambda): watch gate gradients (the monitor already logs beta statistics).

### 3. Gram-Ridge Evidential Head: closed-form (b,d,u) measured from the memory's second moments, not learned
*Origin: mathematics lens.* **Editorial note:** EVIDENTIAL FAMILY (with the next leap): measured evidence counts via an erase-consistent write Gram; dodges the Bengs impossibility by computing, not learning, second-order uncertainty.

**Fuses.** fastweight-math (Mesa/RLS Sherman-Morrison inverse-Gram, MesaNet ridge variance) + evidential-math (subjective-logic Beta bijection; discounted-evidence uncertainty floor u_min(lambda); Denoeux conflict-vs-ignorance split; Bengs impossibility of faithful learned second-order uncertainty) + capacity-math (Welch-coherence crosstalk bound) + math-frontiers (test-time regression).

**Mechanism.** The subjective-logic triple needs two nonnegative evidence counts (r,s); REFA currently asks a trained 3-logit head to hallucinate them. Instead MEASURE them: per (bank, stance) maintain the decayed write Gram G_h^s (16x16), updated by the same transition as the memory so erased evidence is uncounted. The routed quadratic form n^s(q) = sum_h r_h q^T G_h^s q is the discounted number of writes addressing query direction q — exactly the evidence count in the Beta/opinion bijection. Set r = n^+(q), s = n^-(q), (b,d,u) = (r,s,W)/(r+s+W) in closed form, with prior weight W tied to the ridge Lambda; the ridge leverage sigma^2(q) = q^T (G+Lambda)^{-1} q is the 'how unaddressed is this query' signal for free. This dodges the Bengs impossibility and the Aug-2026 abstention-collapse law simultaneously: second-order uncertainty is computed from maintained sufficient statistics, and 'unknown' never enters the trained action space. Conflict K (Denoeux/Dempster) vs ignorance m(Theta)=u separate two unknown types with no extra parameters.

**Math.** Gram recursion (erase-consistent): G_t = A_t G_{t-1} A_t^T + b_t k_t k_t^T, A_t = lambda I - beta_t r_h k_t k_t^T — O(R^2)=256 flops/step/bank, 16KB total state at H=8, 2 stances. Opinion: b = r/(r+s+W), d = s/(r+s+W), u = W/(r+s+W); equivalent Beta(r+Wa, s+W(1-a)). Uncertainty floor theorem (inherited from discounted-Beta): steady-state evidence rate rho gives n_inf <= rho/(1-lambda), hence u >= W(1-lambda)/(W(1-lambda)+rho) — a per-bank computable lower bound on honest uncertainty; expose the routed floor u_min(x) = W / (W + sum_h route_h/(1-lambda_h)). Crosstalk certificate: for keys with coherence mu (Welch floor mu >= sqrt((N-R)/(R(N-1)))), |n(q) - true count of q-aligned writes| <= mu^2 (N-1) max_t b_t — evidence counts carry an error bar. Decision: Chow on projected P = b + a u at t* = lambda_cost/(1+lambda_cost); conformal/ACI wrapper on 1-P for stream-valid coverage.

**Novelty check (adjacency audit).** Attempted searches blocked as recorded in leap 1 (WebSearch budget 200/200; arxiv/google egress-blocked; intended queries: 'Gram matrix evidence count subjective logic fast weight memory', 'ridge leverage epistemic uncertainty linear attention Dirichlet'). Adjacency audit: MesaNet (Jun 2025) maintains (G+Lambda)^{-1} but only to sharpen the read, never as an uncertainty/evidence semantics; EDL (Sensoy 2018) and R-EDL/Re-EDL LEARN evidence via softplus heads — the digest itself notes their magnitudes are provably unfaithful; DIP-EDL derives pseudo-counts from density models, not from the memory's own write Gram; Gaussian-process/ridge predictive variance as uncertainty is classical, but no work maps a decayed, erase-corrected write Gram of a fast-weight memory through the subjective-logic bijection into a support/oppose/unknown head. The specific combination (delta-rule-consistent Gram + Beta bijection + lambda uncertainty floor + Welch error bar) appears unassembled.

**REFA payoff.** Replaces the least-trustworthy component (learned 3-logit head) with a measured one: calibration for the abstention battery comes from arithmetic, so smECE/AURC improvements should be robust across seeds; the u_min(lambda) floor gives the revision task a principled staleness prior; sigma^2(q) distinguishes 'no evidence' (large leverage) from 'conflicting evidence' (large K) — the two unknowns the roadmap wants; total cost 16KB state + ~4K flops/step, trivially within 6GB.

**First experiment.** Add the Gram recursion beside the memory update (reuses A_t pieces already computed in refa.py lines 105-122; ~25 lines), append (n+, n-, sigma^2, u_min) as 4 scalars to the output MLP input (or bypass it with closed-form b/d/u), and run the existing abstention + distractor tasks: compare risk-coverage curves and smECE against the 3-logit baseline at 10 seeds. Hours on the RTX 2060.

**Risk.** Counts writes per direction, not their consistency — 10 weak contradictory-ish supports count like 3 strong ones (mitigate: pair n with read magnitude ||z||); soft routing smears counts across banks (sharper under top-k routing); the erase-consistent Gram recursion G <- A G A^T is quadratic in A and needs the float64 equivalence test extended to confirm no drift.

### 4. Ridge-Coverage Sidecar: per-bank Sherman-Morrison Gram inverses feeding a certified-cheap 'evidence coverage' scalar to the evidential head
*Origin: edge-systems lens.* **Editorial note:** EVIDENTIAL FAMILY: the read-side coverage scalar from the same Gram machinery; splits unknown-no-evidence from unknown-conflict deterministically.

**Fuses.** fastweight-math mesa-layer/MesaNet (exact RLS reads; ridge predictive variance s^2 = q^T (G + Lambda)^{-1} q as a principled 'how much evidence addresses this query' signal) + evidential-math (R-EDL-style heads need an evidence-magnitude input that actually tracks coverage; DIP-EDL's density-derived pseudo-counts) + capacity-math (inverse-Gram preconditioning removes the coherence penalty) — assembled as a READ-SIDE-ONLY sidecar so the write path, kernel, and equivalence gates of leaps 1-3 are untouched.

**Mechanism.** Per (bank, stance), maintain the 16x16 inverse regularized Gram R_h = (G_h + Lambda)^{-1} by Sherman-Morrison rank-1 updates on each routed write (G accumulates beta r k k^T; decay handled by the same forward-decay exponent as leap 3). At query time compute two scalars per stance: coverage c^s = q^T R^s q (large when the query direction is unexplored — a direct 'no evidence addresses this' signal that, unlike a learned u, cannot be trained into overconfidence because it is a deterministic function of the key stream) and optionally the preconditioned read z^s_rls = q^T R^s P^s (P = accumulated k v^T) for coherence-corrected recall. Feed [c^+, c^-] into the output head; keep the plain linear read as the default so this is strictly additive.

**Math.** SM recursion: R <- R - (R k k^T R)/(1/(beta r) + k^T R k), O(R^2) = 256 flops per routed write per bank — with top-2 routing, 1KB fp32 state and ~1k flops/event total. Ridge variance c = q^T (G+Lambda)^{-1} q is the exact Bayesian predictive variance of the linear read under Gaussian design: it separates 'unknown because unexplored' (c large, both stances) from 'known but conflicting' (c small, reads disagree) — the two unknown types the evidential-math sweep shows must be distinguished. RLS read removes the correlated-key interference term entirely (exact recall for any linearly independent key set up to R=16, vs delta rule's residual (1 - beta lambda_i(G)) contraction).

Digest cross-check: MesaNet/mesa-layer use SM/RLS for the READ VALUE and the evidential sweeps use learned Dirichlet heads for uncertainty; the digest's mesa finding suggests s^2 as a classifier feature in one clause but no sweep or cited paper builds the coverage scalar as an untrained, deterministic sidecar specifically to split unknown-no-evidence from unknown-conflict in an opponent-stance memory, nor combines it with forward-decay Gram maintenance for offload compatibility.

Decay of G must match bank decay or coverage goes stale relative to memory contents — tie both to the same lambda_h/forward-decay exponent. If keys collapse to low coherence diversity early in training, c saturates uninformatively; monitor key Gram spectrum (already proposed as a diagnostic in the local-learning sweep).

### 5. Certified Shadow Organ: Bloom + conservative-update CMS + IBLT sidecar for deterministic unknowns and exact bank audit
*Origin: edge-systems lens.* **Editorial note:** CERTIFIED FAMILY (with the next leap): zero-false-negative unknowns and exact audit, entirely host-side.

**Fuses.** followup:streaming-sketch (Bloom zero false negatives; conservative-update count-min one-sided over-count; IBLT exact peeling below the 2-core threshold) + evidential-math (typed unknown: no-evidence vs conflict; abstention must not be a trained action per the Aug-2026 collapse law) + followup:truth-discovery (four-cause unknown taxonomy) — attached to REFA's symbolic (s,r,o,polarity) event stream, which no published sketch-augmented neural memory exploits.

**Mechanism.** Beside the learned banks, maintain three host-RAM sketches per stance, updated on every history event by CPU hashing (overlapped with the GPU step): (a) a Bloom filter over hash(s,r,o) of ever-written facts; (b) a conservative-update count-min keyed by hash(s,r) holding certified upper bounds on evidence mass; (c) one IBLT keyed by hash(s,r,o,polarity) with value (count, last_step). Query path: if the queried key is absent from BOTH Blooms, emit 'unknown' deterministically, bypassing the classifier (zero false negatives makes this a certificate, not a prediction — and it keeps abstention out of the trained action space, exactly the guardrail the Aug-2026 collapse result demands). If present, the classifier arbitrates, receiving the two CMS upper bounds as extra scalar features. Between episodes, IBLT peeling exactly enumerates what was written — ground truth for provenance-conflict scoring and bank-content audits.

**Math.** Bloom: FPR ≈ 0.6185^{m/n} (0.8% at 10 bits/key), FNR = 0 exactly. CU-CMS: a <= a_hat_CU <= a_hat_CMS, Pr[a_hat > a + eps*N] <= delta at w = ceil(e/eps), d = ceil(ln(1/delta)) — d=3, w=272 gives eps=1%, delta≈5% in 13KB per stance. IBLT: m cells of (count, keySum, valSum); insert/delete/merge = cellwise addition; listEntries succeeds w.h.p. iff load t/m < c_3 ≈ 0.81. All three are linear/mergeable, so they survive the forward-decay offload of leap 3 by plain addition.

Searched HF Hub via MCP for 'bloom filter abstention neural memory certified' (zero hits). Digest cross-check: the streaming-sketch sweep proposes per-stance CMS and Bloom filters separately as findings, and evidential-math proposes learned b/d/u heads — but no digest entry or cited paper combines a zero-false-negative certificate path that BYPASSES the learned head with an IBLT audit organ, nor frames one-sided sketch error as the un-trainable abstention channel that sidesteps the arXiv:2608.00301 gradient-collapse failure mode.

These are certifications (assert equality/inequality, tolerance zero), extending the repo's 'exactness gate' culture from numerics to semantics. Payoff: the abstention/calibration milestone gets a deterministic unknown-no-evidence code path and an audit oracle for the provenance-conflict task.

### 6. Sketch-Certified Interval Opinions: one-sided streaming error bounds pushed through the imprecise-Dirichlet calculus
*Origin: mathematics lens.* **Editorial note:** CERTIFIED FAMILY: the interval-Dirichlet composition that turns one-sided sketch bounds into credal opinions with a certified Chow decision.

**Fuses.** followup:streaming-sketch (conservative-update CMS certified overcount; Misra-Gries certified undercount; Bloom zero false negatives; forward-decay exact mergeability) + evidential-math (Beta/opinion bijection; Chow decision rule; Aug-2026 abstention-collapse guardrail) + substrate-2026 (hash-deterministic addressing on symbolic (s,r,o)).

**Mechanism.** REFA's events are symbolic, so beside the geometric banks keep three tiny one-sided structures per stance, keyed by hash(s,r,o): a Bloom filter (absence is CERTAIN), a conservative-update count-min (estimate never undercounts: certified upper bound r_hat), and a Misra-Gries ledger (never overcounts: certified lower bound r_check). The true decayed evidence count then lies in a deterministic interval [r_check, r_hat]. Faithful abstraction: give each bank a scalar excitability e_h updated e_h <- kappa e_h + (write mass routed to h this step), with kappa set so the half-life is ~30-100 events (the '5-hour window' mapped to stream time), and add gamma * e_h to the router logits. Temporally adjacent events then co-allocate into shared banks regardless of content; distant episodes segregate. This is content-free, so it composes with (rather than replaces) content routing, and it converts CROSS-episode interference into WITHIN-episode superposition — which is the kind the delta rule and joint queries can actually resolve. The pre-configuration term falls out for free: e_h reflects activity before the current event. Prediction unique to this port: 'linked recall' — querying fact A transiently biases routing toward the bank holding temporally-adjacent fact B, a measurable priming signature and the first ML test of Cai-style memory linking.

**Math.** e_h(t+1) = kappa e_h(t) + w_h(t), route logits l_h = W_r x / tau + gamma e_h. Ergodicity condition against rich-get-richer collapse: in the top-k regime, a bank that stops winning has e_h -> 0 geometrically, so any bank re-enters competition within log(gamma e_max / delta)/log(1/kappa) steps — collapse requires gamma e_max to exceed the content-logit spread, giving an explicit safe range for gamma. Capacity: with episodes of length L « T and per-episode co-allocation into ~2 of H banks, per-bank load during an episode's queries is ~L instead of ~T/H mixed, so within-episode retrieval SNR = sqrt(R/(L-1)) — for L=16, R=16 this is SNR ~ 1 vs sqrt(16/(200/8)) ~ 0.8 mixed, and crucially the interfering terms are same-episode (queried together, jointly decodable) rather than random.

Fallback: brainmap-2026 lists excitability allocation as [partial] with a one-line 'add recency-of-write term to router logits' — no source ports it; MoM/MoE literature verified across three sweeps uses content-based or load-balancing routing only (load-balance losses push AWAY from co-allocation, the opposite bias); assembly-calculus Hebbian bias is per-content, not per-time. No sweep source implements time-decaying excitability co-allocation or tests linked recall in an ML memory. Nearest neighbor: Kudithipudi-style neurogenesis/allocation heuristics in continual learning (task-level, not event-timescale, no linking prediction).

**REFA payoff.** Episode-coherent bank residency: distractor and provenance-conflict tasks get physical segregation of episodes (interference isolation), the router gains a collapse-resistant exploration mechanism (excitability is content-free and decays), and the bank-residency/VRAM-offload roadmap item gets a principled prefetch signal — banks with high e_h are the working set. ### 19. Query Sculpting: retrieval-induced forgetting via a two-threshold theta read with competitor depression
*Origin: neuroscience lens.* **Editorial note:** Retrieval-induced forgetting as a query-time write rule: memory that sharpens with use; handle the broken invariant with care.

**Fuses.** neuro-scout [absent] RIF / Norman-Newman-Detre oscillating inhibition + fastweight-math EDA decoupled erase address + capacity-math crosstalk law (competitor pruning raises SNR) + the existing is_query no-write invariant in refa.py

**Mechanism.** Biological circuit: retrieval-induced forgetting (Anderson, Bjork & Bjork 1994: retrieving a memory suppresses related competitors cue-independently, typical Rp- cost 5-15%) with the oscillating-inhibition mechanistic model (Norman, Newman & Detre Psych Rev 2007): a theta cycle sweeps the inhibition level; items that become active only when inhibition is LOW are competitors and their active synapses are weakened, while the target — still active when inhibition is HIGH — is strengthened. Retrieval is itself a write that sharpens memory. Faithful abstraction: REFA currently never writes on query steps (line 99-103). On queries, perform TWO reads: strict (low routing temperature / high threshold: top-1 bank, thresholded read) and permissive (high temperature, soft read). The permissive-minus-strict residual identifies competitor content: traces retrievable under weak competition but inconsistent with the emitted answer. Apply a small negative delta write at a learned erase address (EDA-style decoupled: e = normalize(W_e [k; z_perm - z_strict]), NOT the query key itself — so the target is untouched) and a small positive refresh write to the winning trace (countering lambda-decay for used facts: the testing effect).

**Math.** Two-phase read: z_strict = top1_h thresh(q^T M_h), z_perm = sum_h softmax(l_h / tau_high) q^T M_h. Competitor component c = z_perm - proj_{z_strict}(z_perm). Depression: M_h <- M_h - eta_r r_h e (e^T M_h) with e the learned erase address (a pure erase, Householder factor with eigenvalue 1 - eta_r on e — stability free from the existing contraction analysis since eta_r in (0,1)). Refresh: M_h <- M_h + eta_f r_h k z_strict^T (norm-bounded since ||z_strict|| <= ||M||). Capacity effect: each answered query removes competitor mass, so effective T in SNR = sqrt(R/(T-1)) decreases with query count — memory monotonically de-noises with use, opposite in sign to every decay-based mechanism in the sweeps. Rp- prediction: unqueried facts sharing the erase-address neighborhood degrade by ~eta_r per related query — a quantitative confabulation-battery signature matching the human 5-15% effect size.

**Novelty check (adjacency audit).** WebSearch exhausted (intended: 'retrieval induced forgetting machine learning memory network', 'oscillating inhibition Norman Newman Detre neural network implementation', 'query time write linear attention competitor suppression'); fetches egress-blocked. Fallback: neuro-scout tags RIF/oscillating-inhibition as [absent]/'unported query-time write rule' after its dedicated sweep; no fast-weight paper in any sweep writes on read (kNN-LM, mesa, MoM, GDN-2 all keep reads pure); EDA's decoupled erase (Jun 2026) operates at write time only. Plot accuracy vs cumulative query count (predict flat for stock REFA, positive slope with sculpting) and measure the Rp- analog on unqueried related facts (predict small controlled degradation ~eta_r). **Risk.** Breaks the clean 'queries never modify state' invariant (complicates audit/provenance semantics and the float64 equivalence tests — keep flag-gated); early in training the emitted answer is often wrong, so depression entrenches errors (gate eta_r by head confidence/margin); the learned erase address is the weakest link — if it collapses onto k it erases the target (add a cosine-penalty keeping e away from k).

### 20. Reverse-Water-Filling Decay Spectrum: the log-spaced lambda grid derived as a rate-distortion theorem
*Origin: mathematics lens.* **Editorial note:** Derive the decay spectrum instead of tuning it: the log grid as a rate-distortion theorem.

**Fuses.** followup:rate-distortion (Sims fixed-channel C/N law; per-bank AR(1) bit budget; decision-space KL distortion) + temporal-math (log-spaced decay grids, currently justified only empirically/biologically) + capacity-math (SNR = sqrt(R/(T-1)) sets SNR_0) + consolidation-math (Benna-Fusi power-law forgetting as the multi-scale limit).

**Mechanism.** Stop treating the per-bank decays lambda_h as free hyperparameters or biology-inspired defaults: derive them. Model bank h as an AR(1) Gaussian channel whose retrievable information about an event of age Dt is I_h(Dt) = (RD/2) log(1 + SNR_0 lambda_h^{2 Dt}). Given (i) the task's query-age distribution p(Dt) — directly measurable from any battery as the histogram of query-to-evidence lags — and (ii) a total rate budget C fixed by H, R, D and the crosstalk law, choose the spectrum {lambda_h} minimizing expected decision distortion. The variational problem is reverse water-filling over log-age; for scale-free p(Dt) ~ 1/Dt the stationarity condition allocates equal rate per log-age octave, whose unique solution is the GEOMETRIC grid tau_h = 1/(1-lambda_h) = Dmin (Dmax/Dmin)^{(h-1/2)/H}. The SITH/HiPPO-LagT/Benna-Fusi log grid thus becomes a THEOREM (the RD optimum under scale-free query ages), and — more useful — the same machinery outputs the optimal non-log grid for any other measured p(Dt), plus a closed-form answer to 'how many banks do I need' (H >= log(Dmax/Dmin) / log(1+delta) for relative-precision delta). Prediction engine: trained-from-scratch lambda_h should CONVERGE toward the derived grid when and only when the task's p(Dt) matches the assumed one.

**Math.** Objective: J({lambda_h}) = E_{Dt~p}[ min_h sigma^2 2^{-2 R_h(Dt)} ], R_h(Dt) = (RD / 2 N_h) log(1 + SNR_0 lambda_h^{2 Dt}) with N_h the load routed to bank h (Sims C/N division), SNR_0 = R/(T-1) from the crosstalk law. Reverse water-filling: distortion equalized at D_h = min(theta, sigma_h^2) across banks; Lagrangian stationarity dJ/d(log tau_h) = 0 under p(Dt) = c/Dt on [Dmin, Dmax] => tau-grid geometric (equal octave coverage), ratio (Dmax/Dmin)^{1/H}. Decision-space correction: replace MSE by d(x,x_hat) = KL(p(y|x)||p(y|x_hat)) on the 3-simplex — per-fact rate to resolution eps is R ~ 2 log2(1/eps) independent of D, which rescales C but not the grid geometry. Corollaries: (a) error-vs-age curve is piecewise 2^{-2C/N}-exponential with power-law envelope — matching Benna-Fusi's power law as H -> inf; (b) set-size prediction: per-bank recall MSE grows exponentially in facts-per-bank at fixed lambda (testable knee). Fitting procedure: histogram p(Dt) online (KBs), solve the 1-D water level by bisection, set lambda_h — no gradients.

**Novelty check (adjacency audit).** Attempted searches blocked (budget 200/200; intended queries: 'rate distortion optimal forgetting rates multi timescale memory water filling', 'derive log spaced time constants optimal lossy memory query distribution'; arxiv egress verified blocked). Adjacency audit: Sims and Bates-Jacobs do RD working memory over ITEMS, with no temporal decay allocation; HiPPO derives grids from polynomial-approximation measures (a different variational principle — approximation of the whole signal, not decision distortion under a query-age prior); SITH fixes geometric grids axiomatically for scale invariance; Fisher-memory-curve work (Ganguli-Huel-Sompolinsky lineage) analyzes fixed recurrences rather than optimizing decay spectra against a query distribution; Benna-Fusi optimize synapse cascades for memory lifetime, not query-conditional decision distortion. The specific derivation (query-age prior + AR(1) rate + reverse water-filling => decay spectrum, with the log grid as the scale-free special case) appears unassembled.

**REFA payoff.** Converts two hyperparameters into computed quantities: the decay spectrum and the bank count, each with a printed optimality certificate and a falsifiable signature (learned-lambda convergence to the derived grid; exponential facts-per-bank error knee; power-law error-vs-age envelope). Feeds directly into the multi-seed validation and length-extrapolation roadmap items: extrapolation failures decompose into 'rate-starved ages' visible in the water-filling solution before any training run.

**First experiment.** Pure analysis plus existing training runs: (1) 30-line script solving the water-filling allocation for three synthetic query-age distributions (uniform-recent, scale-free, bimodal); (2) train stock REFA with free lambda under each distribution (10 seeds, tiny models — overnight on the 2060) and compare sorted learned 1/(1-lambda_h) to the derived grids (Kendall tau, log-slope). A match under scale-free but not uniform-recent conditions confirms the mechanism; a universal mismatch localizes an optimization pathology worth knowing about anyway.

**Risk.** The AR(1)-Gaussian idealization ignores the erase term (which deletes information non-uniformly) and routing correlations (N_h endogenous to lambda_h) — the derivation is exact only for the decay-only shadow of the model; learned lambdas may fail to converge to the optimum for optimization reasons, making the falsification test one-sided; payoff is scientific (predictions, principled defaults) rather than an immediate accuracy win.
