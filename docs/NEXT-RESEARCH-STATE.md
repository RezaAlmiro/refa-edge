# Next research state — kill the typed-memory founding bet

## Decision

The next experiment is **A2/K1: typed support/opposition banks versus a signed single
store**. It precedes kernel optimization, new architecture leaps, and another parity
extension.

A1 established a small spectral mechanism but did not test the program's founding
claim. K1 is now the highest-value decision because it determines whether REFA remains
an architecture project or narrows toward mechanisms, instruments, and theory.

## Hypothesis

Keeping support and opposition in separate state is more robust than storing polarity
as the sign of one value when evidence is revised, conflicts, or is absent.

The bet survives only if typed memory improves preregistered revision, conflict, and
abstention endpoints beyond seed variability. Biological analogy is not evidence.

## Required comparison

Build one signed-store variant behind the existing model registry. It must share the
same event embedding, address/value projections, router, workspace, classifier,
optimizer, data, and seeds as typed REFA. Match learned parameter count exactly and
report fast-state capacity both ways; state capacity must not be hidden under the word
"parameter-matched."

The signed store writes `+v` for support and `-v` for opposition with the same
erase-before-write rule. The typed model retains `M+` and `M-`. Any readout advantage
caused only by receiving twice as many final features must be controlled with a
capacity-matched signed readout or an explicit ablation.

## Minimum battery before confirmation

1. last-write-wins revision, stratified by revision count and query lag;
2. simultaneous conflict, where both support and opposition evidence remain relevant;
3. unknown/no-evidence close decoys;
4. corrected keyed parity as a regression check, not the primary endpoint;
5. ID length and 4× length OOD.

Calibration must use smECE. Report medians and IQRs over at least ten paired seeds, raw
per-example predictions, confusion matrices, learned gate/decay statistics, crosstalk
load, and hardware/source fingerprints. Freeze the battery and decision rule before
confirmatory seeds.

## Kill rule

Kill Thesis C as an architectural differentiator if typed memory does not beat the
best fair signed-store control on both:

- revision/conflict accuracy by a preregistered practically meaningful margin; and
- OOD abstention/calibration without losing ordinary accuracy.

IQR overlap alone is descriptive, not a statistical decision rule. The preregistration
must choose a paired effect threshold and an uncertainty interval before testing. If K1
fails, retain A1's spectral result as a standalone mechanism and move the program toward
the measured-evidence/provenance instrument lane.

## What not to do yet

- Do not optimize the WY kernel before knowing whether the typed architecture survives.
- Do not claim the A1 parity result supports typed banks; it used one bank and only
  SUPPORT writes.
- Do not tune K1 on confirmatory seeds or rescue typed memory by changing its task.
- Do not start language-scale framing until K4 measures the symbolic-to-text boundary.

## Completion artifact

Ship a short positive or negative report with the frozen protocol, all raw results, and
a direct update to `llm-handoff/04-CRITICAL-ASSESSMENT.md`. A clean negative result is a
successful completion of K1.
